# 🍅 Pomo Focus — ポモドーロ + タスク管理アプリ

完全ローカル動作・無課金・オフライン対応の Web アプリです。
ブラウザの localStorage にデータを保存するので、サーバーも API も不要。
一度どこかに置いてしまえば、Claude Code を解約しても永久に無料で使えます。

## ✨ 機能

- ⏱ ポモドーロタイマー (集中 / 短い休憩 / 長い休憩、時間カスタマイズ可)
- ✅ タスク管理 (追加 / 完了 / 削除 / タイマーと連動)
- 📊 統計 (今日 / 今週 / 累計のセッション数)
- 🌓 ダーク / ライトモード
- 🔔 音通知 + ブラウザ通知
- 📱 PWA 対応 (スマホのホーム画面に追加可能、オフラインでも動作)
- 💾 データのエクスポート / インポート (JSON でバックアップ)
- ⌨ スペースキーで開始/一時停止

## 🚀 使い方 (3パターン)

### パターン1: PCで直接使う (一番カンタン)

`index.html` をダブルクリックするだけ。ブラウザで開いて、ブックマークすれば完了。
※ Service Worker (オフライン機能) は `file://` 経由では動きませんが、アプリ自体は問題なく動作します。

### パターン2: GitHub Pages で公開 (推奨・スマホからも使える)

GitHub アカウントがあれば、5分で世界中どこからでも使える URL が手に入ります。

1. GitHub にログインして「New repository」をクリック
2. リポジトリ名を `pomo-focus` などに設定 (Public にする)
3. 3つのファイル (`index.html`, `manifest.json`, `sw.js`) をアップロード
4. リポジトリの **Settings** → **Pages** を開く
5. 「Source」を **Deploy from a branch** にして **main** ブランチを選択 → Save
6. 数十秒待つと `https://<ユーザー名>.github.io/pomo-focus/` で公開される

スマホでこの URL を開いて「ホーム画面に追加」すれば、ネイティブアプリのように使えます。

### パターン3: Cloudflare Pages で公開 (もっと早い)

1. https://pages.cloudflare.com にアクセスしてサインアップ (無料)
2. 「Upload assets」を選ぶ
3. 3つのファイルをドラッグ&ドロップ
4. プロジェクト名を入力 → Deploy
5. `https://<プロジェクト名>.pages.dev` で公開

## 📂 ファイル構成

```
pomo-focus/
├── index.html      # アプリ本体 (HTML + CSS + JS が全部入り)
├── manifest.json   # PWA設定 (アプリ名、アイコンなど)
└── sw.js           # オフライン動作用のService Worker
```

## 💾 データはどこに保存される?

すべてブラウザの `localStorage` に保存されます。
- サーバーには一切送信されません
- 同じブラウザ・同じ端末でしか見えません (例: PCで保存したデータはスマホからは見えない)
- 端末を変える時や心配な時は、フッターの「データをエクスポート」で JSON ファイルとして保存しておくと安心です

## 🛠 カスタマイズのヒント
